Architecture

How this starter is put together

The workflow continues to render the main report from SQLite using R. A second build step exports chart-friendly JSON and copies this static web shell into the output directory.

That gives you fast hosting options and low operational overhead now, while still leaving room to graduate into a heavier frontend or backend later if we need live filters, auth, or richer APIs.

Current pages

  • A welcome page for first impressions and high-level metrics.
  • A dashboard page with client-side interactive Plotly and Leaflet views.
  • A reports section with static domain pages generated from intersected geographies.
  • A docs page describing calculations, percentiles, and provided variables.
