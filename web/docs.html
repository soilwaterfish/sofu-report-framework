Calculations, percentiles, and provided variables

This page documents the current dashboard logic so we can keep iterating with a shared understanding of where values come from, what is computed, and what still deserves caution.

Data modes Provided + computed FEMS/NFDRS values stay intact. Non-WIMS Synoptic and Zentra get computed enrichments where possible.

Source logic

How values are chosen by source

Source Uses provided values Uses computed values Notes
FEMS / RAWS `gsi`, `kbdi`, weather, fuel-state style metrics Generally none for `gsi` / `kbdi` These values are treated as authoritative and are not overwritten by local calculations.
Non-WIMS Synoptic Weather, soil moisture, some precip fields `gsi`, `kbdi` when enough support data exists Computed metrics are best thought of as proxies and should be cross-checked against nearby RAWS stations.
Zentra Hourly weather and soil signals `gsi`, `kbdi` where the station has enough temperature, humidity/VPD, precip, and site metadata Zentra currently extends coverage, but not every derived metric should be interpreted as equivalent to NFDRS outputs.

Percentiles

What the percentile cards and ribbons mean

Percentiles are built from the daily stats tables. For each station, variable, and day of year, we summarize the historical daily minimum, mean, and maximum values and calculate percentile breakpoints such as `P10`, `P25`, `P50`, `P75`, and `P90`.

  • The color bar shows where the selected day’s value lands relative to that station’s historical context.
  • The cards underneath show the current daily min, mean, and max beside key percentile thresholds.
  • The chart ribbons use percentile envelopes for the selected variable when enough history exists.
  • If no percentile context exists for a site-variable combination, the dashboard falls back to plain values without percentile styling.

Variables

Variables currently surfaced in the dashboard

Soil Moisture 1 / 2

Primary soil moisture channels where available. Summary cards also show 14-day change and trend coloring.

Air Temperature

Daily and recent air temperature trends, plus percentile context when enough history exists.

Humidity

Relative humidity from FEMS, Synoptic, or Zentra daily stats, used both directly and inside some computed paths.

Wind Speed

Daily wind speed summaries, mainly for situational awareness rather than percentile-heavy interpretation.

Precip Accum

Source-specific accumulated precipitation field used where available. Semantics still differ across station families.

Accumulated Precip

Water-year cumulative precipitation derived during export for charting and percentile comparison.

GSI

Provided directly for WIMS/NFDRS stations; computed for non-WIMS Synoptic and Zentra when enough support variables exist.

KBDI

Provided directly for WIMS/NFDRS stations; computed for non-WIMS Synoptic and Zentra using station precipitation normals plus daily temperature and precip.

Code notes

Current calculation scaffolds

These are simplified snapshots of the logic currently used in the workflow. They are here to make review easier, not to replace the source code.

Show `GSI` calculation overview 
i_tmin  = clamp((-2C to 5C ramp using daily Tmin))
i_vpd   = clamp((900 Pa to 4100 Pa ramp using daily VPD))
i_photo = clamp((10h to 11h ramp using daylength))

daily_gsi_proxy = i_tmin * i_vpd * i_photo
gsi = trailing_running_mean(daily_gsi_proxy, 28 days)

For FEMS / RAWS we keep the provided `GSI`. For non-WIMS Synoptic and Zentra, this remains a calibrated proxy, and nearby-station comparison is still part of QA.

Show `KBDI` calculation overview 
inputs:
  daily Tmax
  daily precip
  station mean annual precipitation (PRISM normal)

stateful recurrence:
  if rainfall > 0.2 in:
    reduce yesterday's KBDI

  add drought factor as function of:
    current KBDI
    Tmax
    annual precipitation normal

  clamp result to [0, 800]

KBDI is only computed for non-WIMS Synoptic and Zentra where usable support inputs exist. If precip support is missing, the workflow now prefers to skip the derived KBDI rather than emit obviously bad values.

Show percentile table logic 
group by:
  station_id
  metric_name
  day_of_year_key
  stat_type (value_min / value_mean / value_max)

from complete daily stats:
  p05, p10, p25, p50, p75, p90, p95
  n_years
  min and max source dates

Percentiles are recomputed from the daily stats tables and refreshed incrementally after the initial backfill.

Show current caution list 
- Precip field semantics are not uniform across all sources.
- Computed GSI for non-WIMS / Zentra is a proxy, not a formal NFDRS replacement.
- Computed KBDI depends heavily on usable daily precip support.
- Variable coverage differs by station family and by site.
